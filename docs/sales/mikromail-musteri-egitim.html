05
Mail Rehber · Etiket
Segmentasyon

Önce etiket, sonra liste

  1. Kontak & CRM → üstte Mail Rehber alt sekmesi
  2. Etiket yönetimi kutusuna anlamlı isim yaz (örn. agustos_vip)
  3. Etiket oluştur’a bas
  4. Import / yapıştırırken aynı etiketi seç
  5. Kampanyada hedef = bu etiket
İsimleme: tarih + kaynak + segment. Örn. 2026_08_partner_temiz. “data1” kullanmayın.

Hazır sistem etiketleri (scrub sonrası)

  • mail_valid — gönderilebilir
  • mail_invalid — gönderme
  • mail_mx_ok — MX var
  • mail_disposable — geçici mail
  • mail_role — info@ / noreply@
  • mail_unknown — emin değil

Kampanyada mümkünse sadece doğrulanmış + kendi segment etiketinizi birlikte kullanın.

07
Kontak ekleme · detay
Pratik kurallar

Yüklerken bozmayın

CSV sütunları

  • En az email sütunu
  • Opsiyonel: name, tags, phone
  • İlk satır başlık olsun
  • Excel’den kaydederken XLSX tercih edin

Yükleme panosu

  • Durum rozeti: bekliyor / işleniyor / bitti / hata
  • Hata kutusunu oku — sütun adı yanlış olabilir
  • Sırada birden fazla dosya varsa sırayla gider
  • Takılırsa iptal / admin’e haber
Yapma: Yükler yüklemez 50.000’lik kampanya açmak. Önce scrub bitmeli. Aksi halde bounce domain’i yakar (sizin kotanızı da yer).
Küçük CSV yapıştır: Birkaç bin satır için “details” altındaki metin kutusu yeter. Dev liste için dosya yükleyin.
08
Liste temizleme
Scrub

Göndermeden önce süzgeç

  1. Mail Rehber’de Liste temizle kartına in
  2. Kapsam: ilgili etiketleri işaretle (boş = tümü — dikkat!)
  3. Listeyi temizle veya Seçilileri temizle
  4. İlerleme çubuğu + üst banner’ı izle
  5. Bitince mail_valid / mail_invalid etiketlerini kontrol et
SMTP ping “pasif kullanıcı” bulmaz; mailbox kabul ediyor mu bakar. Catch-all domainler mail_unknown / catch-all olabilir.

Sonuç ne olur?

  • Invalid / disposable / role → suppression (ayara bağlı)
  • Valid → kampanyaya uygun
  • Kampanyada “Sadece doğrulanmış” açın

Ne zaman tekrar scrub?

  • Yeni büyük liste geldiğinde
  • Bounce oranı yükseldiğinde
  • Haftalık bakımda (önerilir)

11
Şablon · kurallar
Deliverability

Spam’e düşürmeyen içerik

Yap

  • Kısa, net konu
  • Tek ana CTA linki
  • {{link:https://…}} ile takip
  • İsim yoksa sistem kibar varsayılan kullanır
  • Isınmada sade metin

Yapma

  • ALL CAPS + !!!
  • Şüpheli kısaltıcı / bozuk link
  • Ağır HTML / spam kelime yığını
  • Test etmeden toplu basmak
  • Aynı HTML’i her gün aynı kitleye
Affiliate / üye eşleme linki: Özel link biçimi ile tıklayan kişi CRM’deki kontakla eşlenebilir. Admin kurulumunu yaptıysa şablonda ilgili seçenek görünür.

13
Kampanya · detay
Kota & durumlar

Neden durur, ne yaparsınız?

3 fren

  • Hesap günlük kotası
  • Firmanızın mail kredisi
  • Domain daily / hourly cap

Biri dolunca kampanya kontrollü stop olur. Kalan alıcılar “yanmış” sayılmaz — sonra devam / yeni kampanya.

Durum sözlüğü

  • kuyrukta / gönderiliyor
  • tamamlandı
  • duraklatıldı / iptal
  • durduruldu (kapasite)
  • hata

Detay satırından ilerleme ve fail sebebini okuyun.

Karışık etiket: Birden fazla etiket OR birleşimidir. Bir etiketten kısmi kişi seçtiyseniz o etiketin “hepsi” otomatik düşer — özet satırını okuyun.

Rapor KPI + kampanya tablosu (demo)

15
IVR & Ayarlar
İleri seviye

İki ek modül (kısa)

IVR Otomasyon

  • Arama cevaplanınca mail tetikler
  • Kural: ad + şablon + domain + gecikme (sn)
  • Webhook URL/secret santrale verilir
  • Kurulum genelde admin + santral ekibi

Sizden beklenen: doğru şablon ve gecikme süresi.

Sistem Ayarları (yetkiye göre)

  • Scrub: SMTP ping aç/kapa
  • Invalid / disposable / role → suppression
  • “Kampanyada varsayılan: sadece doğrulanmış”
  • SMTP alanları çoğu müşteride kilitli / admin

Emin değilseniz varsayılanları bozmayın.

16
İlişki CRM
Kontak & CRM · alt sekme

Rehber ≠ ilişki takibi

Pipeline aşamaları

Aday → Temas → İlgili → Dönüşen / VIP · Uyuyan · Kayıp

  • Skor 0–100 (açılma/tık/gönderim sinyali)
  • Sıcak kontak (50+) KPI
  • Not ekle, takip görevi (vadeli)
  • Zaman çizelgesi: send/open/click/not/görev

Ne zaman kullanırsınız?

  • Tıklayan / açan kişiyi ara
  • VIP’e manuel yükselt
  • Operatöre görev ata
  • “Skorları yenile” ile toplu güncelle
Mail Rehber = liste makinesi. İlişki CRM = insan takibi. İkisini karıştırmayın.

Günlük ritim
Checklist

Her gün operatör rutini

Sabah

  1. Dashboard başarı oranı
  2. Kredi / kapasite yeterli mi?
  3. Dün fail/bounce var mı?
  4. Yeni liste varsa scrub

Öğleden sonra

  1. Test mail (spam klasörü)
  2. Kampanyayı cap içinde gönder
  3. Rapor oku
  4. Sıcak kontaklara CRM not/görev
  5. Yarınki etiket + şablon hazırla
18
Sık hatalar
Yapmayın

Bunları görürsek eğitim yarım demektir

  • Scrub’suz toplu gönderim
  • Etiketsiz “tüm rehber” kampanyası
  • Domain’i elle zorla sabitlemek (gerekmedikçe)
  • Stub moddayken “neden mail gitmiyor?”
  • Aynı kişiye aynı gün 3 kampanya
    • Test etmeden HTML yayınlamak
    • Kota dolunca panikle yeni domain istemek (önce scrub/şablon)
    • Invalid etiketini hedef seçmek
    • CRM notu yazmadan “sıcak” diye aramamak
    • Admin işlerini (DNS/ısıtma) müşteri panelinde aramak
    Altın kural: Temiz etiket + doğrulanmış liste + sade şablon + otomatik domain + rapor. Bu dörtlü bozulursa hacim artırma.
